Applies to ALL my projects. If you have any issue with my projects, send it here. Versions to add, features to add, bugs to fix, and everything else I need to do.

### To make a bug report issue, please follow these steps:
* Link the project(s) that this applies to. Make sure the link is a Modrinth link. In some cases where there are variants or very similar projects, tell me "all Dye Buttons projects" or "all Easy Farm projects."
* Give the MC version, link the project versions, and give other details to help me reproduce the bug. 
* Tell me what the issue is, what you did to cause it, and any other info that may help. ("I noticed that, in <project_name>, the recipe doesn't have an advancement that adds it to the recipe book. Since my server will not have a list of recipes, they will need to go to the Modrinth page the first time they craft the recipe.")
* Test it in **vanilla** first (a new instance with only dependencies). If it's a mod compatibility issue, this would help me figure that out faster.
* Wait for a response, be patient, and check your issue for a response. It's possible that I may need additional information.
* If you don't think you can check frequently enough to respond, or you don't have a GitHub account, go to [my Discord server](https://discord.gg/V9gJvEU4YK) and ask in the questions channel.<br>
### To suggest features or versions, please follow these steps:
* Try to avoid unreasonable requests ("can you port the datapack to 1.8" (datapacks were added later) and features that would either not be relevant to the project's purpose or be extremely hard to design for the project's version and loaders).
* Describe what I should add in detail. Explain any game design features that should be added, and try to make sure I understand what to add.
* Don't get mad if I say no. I'm choosing to update these projects for barely any revenue, and I shouldn't be expected to do everything immediately. Updates will be made, and I will try to do my best, but I may not be able to immediately do something, or do it at all.
* You can even suggest projects, but make sure you know what you're asking first. I do mostly datapacks and resource packs, so making a server plugin or a custom boss are probably unrealistic (at least for now, I may do other project types later).

The code will NOT be hosted here. In my Modrinth pages, you may find a link to a GitHub repository for the project, but there is no code here. To find code for other projects, such as datapacks and resource packs, please download the datapack or resource pack version (should be a .zip, NOT a packaged .jar). Then unzip the version, and the full source code should be right there.
